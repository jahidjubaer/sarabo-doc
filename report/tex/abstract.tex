\chapter*{Abstract}
Most electronics repair in Bangladesh still happens informally. A customer hands over a device without knowing what it will cost or how the work is going, and independent technicians have no proper way to find jobs or get paid. In this project I built \textbf{Sarabo}, a web platform that turns a repair into a tracked service with clear prices and a full record of every step, used by three kinds of people. A \emph{Customer} describes the problem (with optional AI help in Bangla, English or Banglish) and books a pickup time. They then compare ranked offers from qualified local technicians, pay an inspection fee that is later taken off the final price, approve an itemised quote, pay and follow the repair, and the finished repair comes with a 30-day warranty. A \emph{Technician} finds work on an open jobs board, sends offers, inspects the device, quotes, repairs it and withdraws earnings through bKash. An \emph{Admin} approves technicians, looks after a catalogue of 45 services, deals with refunds, disputes and stalled work, and reads reports that include an AI summary.

Sarabo is built with React 19, Node.js/Express 5 and MongoDB. It uses Firebase Authentication, Stripe (in test mode), Supabase storage and Google Gemini, and it is deployed on Vercel. The server checks every step that changes money or a request's state and runs it inside a database transaction, and no request is ever left waiting without a deadline or an admin alert. The system passes \servertestcount{} automated server checks and \clienttestcount{} browser tests in continuous integration.

\paragraph*{Keywords:} Electronics repair, service marketplace, workflow management, React, Express, MongoDB, Stripe, generative AI.
