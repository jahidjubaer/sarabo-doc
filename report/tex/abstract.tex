\chapter*{Abstract}
Electronics repair in Bangladesh is largely informal: customers hand over a device without knowing the price or its progress, and independent technicians have no structured way to find work or get paid. This project presents \textbf{Sarabo}, a web platform that turns repair into a tracked, priced and auditable service for three roles. A \emph{Customer} describes the problem (optionally with AI help in Bangla, English or Banglish), books a pickup window, compares ranked offers from qualified local technicians, pays an inspection fee that counts toward the final price, approves an itemised quote, pays, tracks the repair and is covered by a 30-day warranty. A \emph{Technician} finds work on an open jobs board, sends offers, inspects, quotes, repairs and withdraws earnings through bKash. An \emph{Admin} approves technicians, manages a 45-service catalogue, resolves refunds, disputes and stalled work, and reads reports with an AI summary.

Sarabo is built with React 19, Node.js/Express 5 and MongoDB, using Firebase Authentication, Stripe (test mode), Supabase storage and Google Gemini, and is deployed on Vercel. Every money- or state-changing step is checked on the server and runs in a database transaction, and every waiting state has a deadline or an admin alert. The system passes \servertestcount{} automated server checks and \clienttestcount{} browser tests in continuous integration.

\paragraph*{Keywords:} Electronics repair, service marketplace, workflow management, React, Express, MongoDB, Stripe, generative AI.
